# Linear onboarding

This rehearsal tracks its work in Linear. Ticket ADV-1 is Linear's own "Welcome to
Linear" walkthrough; this file keeps its resources and this repo's ticket/branch
conventions in one place for whoever picks up the next ticket.

- Slack community — connect with other Linear users and get tips:
  https://linear.app/join-slack
- Live onboarding session — learn the essentials and see demos of core workflows:
  https://lu.ma/welcome-to-linear?utm_source=onboarding
- In-app support: press `?` in the bottom left, then choose "Contact us".

## Conventions in this repo

- Tickets use the `ADV` prefix (for example `ADV-1`).
- Work for a ticket goes on a branch named with the bare ticket ID (for example
  `ADV-1`), not a slug or prefix variant.
